# 🥗 AI WeightLoss — Telegram Mini App + Website

AI-помощник для похудения. Персональный рацион, подробные рецепты, чат с ИИ, трекер веса с графиком и анализом. Работает как в Telegram Mini App, так и на сайте.

## ✨ Возможности

- 🎬 **Кинематографичная заставка** — тёмная сцена с лучами и частицами, «Пропустить» внизу справа → соглашение
- 📋 **Пользовательское соглашение** и регистрация
- ⚙️ **Настройки** — вес, рост, возраст, цель, срок, 80+ продуктов-виджетов, аллергии, сложность диеты
- 🍽️ **AI-рацион** — 5 приёмов пищи с **подробными рецептами** (время, ингредиенты, шаги, советы), кнопка «Составить ещё раз» (блюда никогда не повторяются)
- 💬 **Чат с ИИ-диетологом** — отвечает только на темы похудения, диеты, продуктов, напитков и тренировок
- ⚖️ **Трекер веса** — график показывает **все записи** с подписями значений и датами
- 📊 **AI-анализ прогресса** — темп похудения, застой, рекомендации и мотивация
- 🌐 **Переходники** — «Открыть сайт» из Telegram и «Перейти в Telegram» с сайта
- 👤 **Менеджер + тикеты** — система обращений в боте
- 🤖 **Общий AI** — ключ не нужен, работает у всех пользователей

## 🚀 Запуск

### Бот (менеджер + тикеты + Mini App)
```bash
cd bot
pip install -r requirements.txt
python main.py
```
Или `start_all.bat` (бот + AI-прокси).

### Настройка менеджера
В `bot/main.py` замените `ADMIN_IDS = {123456789}` на ваш Telegram ID (узнать можно у @userinfobot). Менеджер получает уведомления о новых тикетах и отвечает командой:
```
/reply <номер> <текст ответа>
/alltickets — все тикеты
```

### Mini App / сайт
- Сайт: https://aifoodbot.duckdns.org/
- Бот: https://t.me/foodAi1_bot
- Локально: `cd miniapp && python -m http.server 8080`

## 🌐 Смена домена на бесплатный (DuckDNS)

1. Зарегистрируйтесь бесплатно: https://www.duckdns.org (вход через GitHub/Google/Reddit)
2. Создайте поддомен, например `aifoodbot` → получится `aifoodbot.duckdns.org`
3. Скопируйте ваш **токен** из дашборда
4. Выполните (PowerShell):
   ```powershell
   $env:DUCKDNS_TOKEN="ваш_токен"
   $env:DUCKDNS_DOMAIN="aifoodbot"
   python bot/set_duckdns.py
   ```
   Скрипт обновит A-запись на IP GitHub Pages и создаст `docs/CNAME`.
5. В GitHub: **Settings → Pages → Custom domain** → введите `aifoodbot.duckdns.org` → Save
6. Задеплойте: `git add -A && git commit -m "Custom domain" && git push`
7. Обновите URL в `bot/main.py` (`MINI_APP_URL`, `SITE_URL`) и в `app.js` (`SITE_URL`) на новый домен

После этого сайт и Mini App будут доступны на `https://aifoodbot.duckdns.org`.
