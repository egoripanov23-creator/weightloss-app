# 🥗 AI WeightLoss — Telegram Mini App

AI-помощник для похудения прямо в Telegram. Персональный рацион, отслеживание веса, AI-поддержка.

## ✨ Возможности

- 📋 **Пользовательское соглашение** — при первом запуске
- 👤 **Регистрация** — имя, email
- ⚙️ **Настройки** — вес, рост, возраст, целевой вес, срок, любимые продукты (виджеты), аллергии, сложность диеты
- 🍽️ **AI-рацион** — персональный план питания на день, генерация нового плана по кнопке
- ⚖️ **Трекер веса** — ввод веса, график прогресса, история
- 💚 **AI-поддержка** — мотивирующие сообщения на основе прогресса
- 🎨 **3D-интерфейс** — современный, минималистичный дизайн с Three.js

## 🚀 Быстрый старт

### Бот
```bash
cd bot
pip install -r requirements.txt
python main.py
```

### Mini App
Откройте в Telegram: https://t.me/YOUR_BOT_USERNAME

### Локальный просмотр
```bash
cd miniapp
python -m http.server 8080
```
